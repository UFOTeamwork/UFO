STEP 8 ¡ª RELEVANCE CLASSIFICATION
==================================================

For EACH global attribute and part, determine its SOURCE OF INFORMATION.

IMPORTANT:

The decomposition describes the structure of the
PREDICTED GENERATED IMAGE.

Relevance does NOT describe whether the element
exists in the generated structure.

Instead, relevance traces WHERE the information
for that element originates from:

? the reference image
? the editing prompt
? or both

ONLY three labels are allowed:

image_only
text_only
text_and_image


--------------------------------------------------
STRUCTURE ORIGIN RULE
--------------------------------------------------

The subject decomposition represents the
expected structure of the GENERATED IMAGE
after applying the editing prompt.

Therefore the decomposition may contain elements:

? already visible in the reference image
? newly introduced by the prompt
? modified versions of existing elements

Relevance classification determines which
source contributes the information needed
to define each element in the generated structure.


--------------------------------------------------
SOURCE DETERMINATION PROCESS
--------------------------------------------------

Relevance MUST be determined AFTER the predicted
edited structure and part decomposition are completed.

Follow this reasoning order:

1. Identify whether the element already exists
   in the reference image.

2. Identify whether the prompt introduces,
   constrains, or modifies this element.

3. Determine which source contributes the
   information required to define the element
   in the generated image.

Assign the relevance label accordingly.


--------------------------------------------------
image_only
--------------------------------------------------

Definition:

The element is determined entirely by
visual information from the reference image.

Conditions:

? The element exists in the reference image

AND

? The prompt does NOT introduce,
  modify, or constrain it

Interpretation:

The generated structure keeps the same
element directly from the reference image.

The prompt has no influence on this element.


--------------------------------------------------
text_only
--------------------------------------------------

Definition:

The element is introduced entirely
by the editing prompt.

Conditions:

? The element does NOT exist in the reference image

AND

? The prompt explicitly introduces
  or requires this element

Interpretation:

The element appears in the generated
structure only because the prompt
requires it.


Typical cases include:

? newly added objects
? newly added clothing
? newly introduced accessories
? newly introduced tools or props
? newly introduced text, symbols, or logos


--------------------------------------------------
text_and_image
--------------------------------------------------

Definition:

The element in the generated structure
is determined jointly by the reference image
and the editing prompt.

Conditions:

? The element corresponds to something
  visible in the reference image

AND

? The prompt modifies, constrains,
  or reinterprets it


Interpretation:

The reference image provides the base structure,
while the prompt specifies how the element
should appear in the generated result.


Examples:

Reference image: a photo of an animal  
Prompt: "A carved ice sculpture of the animal"

¡ú element: animal shape  
¡ú relevance: text_and_image  
(image provides shape, prompt defines material)


Reference image: man without helmet  
Prompt: "The man wears a metal helmet"

¡ú part: helmet  
¡ú relevance: text_only


Reference image: woman standing  
Prompt: "The woman is running"

¡ú global_attribute: pose  
¡ú relevance: text_and_image

STEP 9 ¡ª REWARD SCORING POLICY
==================================================

Each global attribute and part MUST receive
an integer reward score from 1 to 5.

The reward score represents the structural
importance of the element for evaluating
editing correctness.

The score MUST follow the rules below.


--------------------------------------------------
REWARD = 5 (CRITICAL STRUCTURE)
--------------------------------------------------

Assign reward 5 when the element is:

? explicitly required by the edit prompt  
? a primary target of the editing instruction  
? a core identity-defining component of the subject  
? structurally critical for determining whether
  the edit was executed correctly

If the edit prompt directly modifies
a specific region or attribute,
that element MUST receive reward 5.



--------------------------------------------------
REWARD = 4 (MAJOR STRUCTURE)
--------------------------------------------------

Assign reward 4 when the element is:

? a major structural component of the subject  
? visually dominant in the image  
? important for preserving subject identity  
? potentially affected indirectly by the edit

Major structural regions normally receive
reward values in the range of 4.



--------------------------------------------------
REWARD = 3 (SECONDARY STRUCTURE)
--------------------------------------------------

Assign reward 3 when the element is:

? a normal structural component of the subject  
? visible but not identity-defining  
? not explicitly mentioned in the prompt  
? only moderately relevant for edit evaluation



--------------------------------------------------
REWARD = 2 (MINOR STRUCTURE)
--------------------------------------------------

Assign reward 2 when the element is:

? a small structural component  
? weakly relevant to evaluating the edit  
? visually minor or peripheral within the subject



--------------------------------------------------
REWARD = 1 (LOW IMPORTANCE)
--------------------------------------------------

Assign reward 1 only when:

? the element exists structurally
? but has minimal relevance to edit evaluation

Use this score sparingly.

Primary body regions or major components
should NOT receive reward 1.



--------------------------------------------------
SCORING PRIORITY ORDER
--------------------------------------------------

When multiple criteria apply,
priority MUST follow this order:

EDIT TARGET
> IDENTITY STRUCTURE
> VISUAL DOMINANCE
> SECONDARY STRUCTURE

Elements directly affected by the prompt
must always receive the highest scores.



--------------------------------------------------
REWARD DISTRIBUTION CONSTRAINTS
--------------------------------------------------

To maintain structural consistency:

? At least one element MUST have reward ¡Ý 4  
? Elements with reward = 5 should be limited  
? Major structural regions should typically
  receive reward values of 3 or higher  
? Avoid assigning reward 1 to core parts
